## 0. 방향 결정

이 문서는 기존에 나뉘어 있던 아이디어를 하나로 합친 기준 문서다.

최종 방향은 전략 시뮬레이션이나 패널형 방치 게임이 아니다. 핵심은 **플레이어가 캐릭터를 직접 움직이는 아케이드 타이쿤**이다.

```
캐릭터를 직접 움직인다
→ 맵에서 자원을 줍는다
→ 시설에 넣는다
→ 생산/판매된다
→ 돈을 줍는다
→ 건설 존에 돈을 투입해 식당을 확장한다
→ 직원이 내가 하던 동선을 자동화한다
```

PC/에디터에서는 방향키나 WASD로 테스트할 수 있지만, 실제 모바일에서는 왼쪽 가상 조이스틱으로 조작한다. 버튼을 누르는 게임이 아니라, **이동 자체가 조작이고 행동**인 게임이다.

## 1. 한 줄 컨셉

고양이 셰프 냥스타를 조이스틱으로 직접 움직여 재료를 줍고, 요리하고, 손님에게 나르고, 바닥의 돈을 쓸어 담아 식당을 확장하는 한 손 모바일 타이쿤.

## 2. 엘리베이터 피치

플레이어는 작은 숲속 식당을 운영하는 고양이 셰프 **냥스타**가 된다. 식당 뒤 강가와 숲으로 직접 걸어가 생선, 베리, 버섯, 나무 같은 자원을 줍고, 머리 위에 스택으로 쌓아 식당으로 돌아온다.

그릴이나 주스기 같은 생산 시설 앞에 서면 재료가 자동 투입되고, 시간이 지나 완성된 음식이 나온다. 플레이어는 완성된 음식을 다시 머리 위에 쌓아 손님 테이블로 가져가고, 손님이 식사를 마치면 테이블이나 바닥에 돈 더미가 생긴다. 돈 더미를 지나가면 골드가 빨려 들어오고, 그 골드로 건설 존에 서서 새 테이블, 새 조리대, 새 채집 구역, 직원 고용 존을 해금한다.

초반에는 내가 직접 모든 일을 한다. 중반부터는 직원이 채집, 조리, 서빙, 돈 수거를 하나씩 자동화한다. 재미의 흐름은 **내 발로 뛰는 손맛 → 점점 커지는 식당 → 직원 자동화 → 더 큰 확장**이다.

## 3. 핵심 재미

1. **이동이 곧 조작**
   조이스틱 하나로 배우고 끝난다. 캐릭터가 존에 들어가거나 서 있으면 행동이 자동 진행된다.

2. **스택 운반의 만족감**
   재료와 음식을 머리 위에 쌓아 나른다. 스택이 높아지고 출렁일수록 성장감이 보인다.

3. **동선 최적화**
   어떤 순서로 강, 숲, 그릴, 테이블, 돈 더미, 건설 존을 도느냐가 효율을 만든다.

4. **돈 줍기의 도파민**
   판매 수익은 자동 입금이 아니라 바닥의 돈 더미로 나온다. 플레이어가 직접 지나가며 쓸어 담는다.

5. **눈에 보이는 확장**
   골드를 들고 건설 존에 서 있으면 비용이 줄어들고, 완료 시 새 시설이 생긴다.

6. **직원 자동화**
   내가 하던 반복 동선을 직원이 대신한다. 플레이어는 더 큰 목표와 병목 해결에 집중한다.

## 5. 플랫폼과 조작

### 5.1 모바일 조작

- 화면 왼쪽 하단: 고정 또는 플로팅 가상 조이스틱
- 오른손 영역: UI 클릭, 상점, 업그레이드, 보상형 광고 선택
- 기본 플레이 중 별도 액션 버튼 없음
- 존 진입과 체류가 모든 액션을 대체

### 5.2 에디터/PC 테스트 조작

- WASD 또는 방향키: 이동
- 마우스 드래그: 모바일 조이스틱 대체 입력
- 디버그 키는 개발 빌드에서만 사용

### 5.3 입력 원칙

- 첫 5초 안에 조작법을 이해해야 한다.
- 플레이어가 화면을 읽기 전에 몸으로 먼저 이해해야 한다.
- 버튼을 늘리기보다 맵 위 존과 시각적 유도선을 늘린다.

## 6. 코어 게임플레이 루프

### 6.1 순간 루프

```
[자원 존으로 이동]
→ 자원이 자동으로 머리 위에 스택
→ 생산 시설로 이동
→ 재료 자동 투입
→ 완성품 픽업
→ 테이블/카운터로 이동
→ 손님에게 자동 서빙
→ 돈 더미 생성
→ 돈 더미를 지나가며 수거
→ 건설/업그레이드 존에서 골드 투입
```

### 6.2 세션 루프

```
골드 획득
→ 테이블/조리대/채집 구역 확장
→ 손님 증가
→ 혼자서는 동선이 빡빡해짐
→ 직원 고용
→ 자동화로 병목 완화
→ 더 먼 자원/고급 메뉴 해금
```

### 6.3 장기 루프

```
숲속 노점
→ 작은 오두막 식당
→ 넓은 숲 식당
→ 강가 확장
→ 고급 메뉴 라인
→ 직원 자동화
→ 2호점 또는 신규 지역 업데이트
```

## 7. 월드와 맵 구조

### 7.1 기본 화면

- 세로 화면 탑뷰 또는 기울어진 2.5D 뷰
- 중앙: 식당/주방/테이블
- 좌측 또는 하단: 강가 자원 구역

- 식당 주변: 건설 존, 업그레이드 존, 직원 고용 존

### 7.2 주요 존

| 존 | 역할 | 플레이어 행동 |
|----|------|---------------|
| 채집 존 | 생선, 베리, 버섯, 나무 획득 | 존에 서 있으면 자동 수집 |

| 돈 더미 | 골드 수거 | 지나가면 흡수 |
| 건설 존 | 새 시설 해금 | 골드를 보유한 상태로 서 있기 |
| 업그레이드 존 | 시설/캐릭터 강화 | 골드 투입 |
| 직원 고용 존 | 자동화 해금 | 비용 지불 후 직원 생성 |

## 8. 플레이어 시스템

### 8.1 캐릭터

플레이어 캐릭터는 고양이 셰프 냥스타다. 이동, 운반, 투입, 서빙, 돈 수거, 건설 참여를 모두 담당한다.

### 8.2 성장 스탯

| 스탯 | 효과 |
|------|------|
| 이동 속도 | 동선 효율 증가 |
| 스택 용량 | 한 번에 운반 가능한 자원/음식 증가 |
| 채집 속도 | 자원 존에서 아이템을 얻는 간격 감소 |
| 투입 속도 | 시설에 자원을 넣는 속도 증가 |
| 수거 반경 | 돈 더미 흡수 거리 증가 |

### 8.3 스태킹 규칙

- 기본 용량은 3개.
- 업그레이드로 20개 이상까지 확장 가능.
- 초반에는 한 번에 한 종류만 운반한다.
- 후반 트레이 업그레이드로 2종 운반을 해금할 수 있다.
- 스택 아이템은 머리 위에서 물리적으로 쌓이고 살짝 출렁인다.

## 9. 자원 시스템

### 9.1 자원 종류

| ID | 자원 | 채집 위치 | 용도 | 초반 여부 |
|----|------|-----------|------|-----------|
| RES_FISH | 작은 생선 | 강가 | 생선구이 | 시작 |
| RES_BERRY | 산딸기 | 베리밭 | 베리주스/디저트 | 시작 또는 첫 확장 |
| RES_MUSHROOM | 버섯 | 숲길 | 버섯 수프 | 중반 |
| RES_WOOD | 나무 | 숲 | 건설/시설 업그레이드 | 초반 |
| RES_SALMON | 큰 연어 | 먼 강가 | 고급 요리 | 중반 |
| RES_HONEY | 꿀 | 숲 깊은 곳 | 고급 디저트 | 후반 |

### 9.2 채집 방식

- 자원 존에 들어가면 일정 간격으로 아이템이 생성되어 스택에 들어간다.
- 용량이 가득 차면 더 이상 수집되지 않는다.
- 다른 종류를 들고 있으면 새로운 종류를 줍지 못한다.
- 멀리 있는 자원일수록 가치가 높다.

## 10. 생산 시설

### 10.1 시설 목록

| 시설 | 입력 | 출력 | 역할 |
|------|------|------|------|
| 그릴 | 생선 | 생선구이 | 시작 시설 |
| 주스기 | 베리 | 베리주스 | 첫 확장 |
| 수프 솥 | 버섯 + 생선 | 버섯 수프 | 중반 복합 레시피 |
| 화덕 | 연어 | 연어 스테이크 | 고급 판매 |
| 디저트 바 | 꿀 + 베리 | 허니 디저트 | 후반 수익 |

### 10.2 생산 규칙

- 재료를 들고 시설 존에 서면 1개씩 빠르게 투입된다.
- 투입된 재료는 시설 내부 버퍼에 저장된다.
- 조리 시간 후 완성품이 출력 슬롯에 생성된다.
- 출력 슬롯이 가득 차면 생산이 멈춘다.
- 플레이어 또는 직원이 완성품을 픽업해야 생산 흐름이 이어진다.

## 11. 손님과 판매

### 11.1 손님 흐름

```
입장
→ 줄서기 또는 빈 테이블 탐색
→ 주문 말풍선 표시
→ 대기
→ 음식 수령
→ 식사
→ 돈 더미 생성
→ 퇴장
```

### 11.2 손님 종류

| ID | 손님 | 주문량 | 지불 배수 | 인내심 | 해금 |
|----|------|--------|-----------|--------|------|
| CUST_RABBIT | 토끼 | 1 | 1.0 | 높음 | 시작 |
| CUST_RACCOON | 너구리 | 1~2 | 1.0 | 보통 | 시작 |
| CUST_FOX | 여우 | 2 | 1.2 | 보통 | 식당 Lv.2 |
| CUST_BEAR | 곰 | 3 | 1.5 | 낮음 | 식당 Lv.2 |
| CUST_PENGUIN | 펭귄 | 2 | 1.8 | 낮음 | 식당 Lv.3 |
| CUST_VIPCAT | VIP 고양이 | 1 | 3.0 | 매우 낮음 | 식당 Lv.3 |

### 11.3 돈 더미

- 손님이 식사를 끝내면 테이블 또는 계산대 근처에 돈 더미가 생긴다.
- 돈은 자동 입금되지 않는다.
- 플레이어가 지나가거나 직원이 수거해야 골드가 된다.
- 돈 더미는 시각적으로 쌓일수록 플레이어에게 수거 욕구를 준다.

## 12. 건설과 확장

### 12.1 건설 방식

- 잠긴 시설 위치에는 반투명 실루엣과 가격이 표시된다.
- 플레이어가 건설 존에 서 있으면 보유 골드가 조금씩 투입된다.
- 비용이 0이 되면 시설이 즉시 활성화된다.
- 건설 중 존을 벗어나도 진행도는 유지된다.

### 12.2 초반 확장 순서

1. 그릴, 테이블 1개, 강가 생선 존
2. 테이블 2 건설
3. 베리밭 건설
4. 주스기 건설
5. 직원 고용 존 해금
6. 첫 직원 고용
7. 버섯 숲길 해금
8. 수프 솥 건설
9. 강가 먼 구역 해금
10. 화덕 건설

## 13. 직원 자동화

### 13.1 직원의 목적

직원은 플레이어가 반복하던 동선을 실제로 대신 수행한다. 단순 수치 보너스가 아니라, 맵 위에서 움직이는 자동화 캐릭터로 보여야 한다.

### 13.2 직원 역할

| 역할 | 행동 |
|------|------|
| 채집 직원 | 자원 존에서 재료를 주워 창고/시설로 운반 |
| 조리 직원 | 생산 시설에 재료 투입 및 완성품 정리 |
| 서빙 직원 | 완성 음식을 테이블로 운반 |
| 계산/청소 직원 | 돈 더미 수거, 후반에는 테이블 정리 |

### 13.3 직원 성장

- 직원 이동 속도
- 직원 스택 용량
- 직원 담당 범위
- 직원 작업 우선순위

## 14. 경제와 밸런스

### 14.1 재화

| 재화 | 획득 | 사용 |
|------|------|------|
| 골드 | 손님 판매, 돈 더미 수거, 오프라인 수익 | 건설, 업그레이드, 직원 고용 |
| 보석 | 미션, 광고, IAP | 시간 단축, 부스트, 치장 |
| 재료 | 채집 | 생산 시설 입력 |
| 나무 | 채집 | 건설/업그레이드 보조 재료 |

### 14.2 비용 곡선

```
다음 레벨 비용 = 기본 비용 × 성장 계수 ^ 현재 레벨
```

- 초반 성장 계수: 1.12~1.18
- 직원 고용 성장 계수: 1.35~1.45
- 새 시설 가격은 플레이어가 2~4분 안에 목표로 삼을 수 있어야 한다.

### 14.3 의도된 병목

- 초반: 스택 용량 부족

- 자동화 전: 서빙/돈 수거 동선 과부하

## 15. UI/UX

### 15.1 기본 HUD

- 좌측 하단: 가상 조이스틱

- 화면 중앙: 월드와 존, 말풍선, 건설 가격

### 15.2 인게임 UI 원칙

- 핵심 행동은 버튼이 아니라 월드 안에서 발생한다.
- 업그레이드와 건설도 가능하면 맵 위 존으로 표현한다.
- UI 패널은 캐릭터 업그레이드, 상점, 오프라인 정산처럼 꼭 필요한 경우만 사용한다.
- 튜토리얼 문장보다 화살표, 반짝임, 존 강조를 우선한다.

### 15.3 온보딩 60초

1. 강가 생선 존이 반짝인다.
2. 플레이어가 생선 3개를 스택한다.
3. 화살표가 그릴로 안내한다.
4. 생선이 자동 투입되고 생선구이가 나온다.
5. 테이블 손님 말풍선이 생선구이를 요구한다.
6. 플레이어가 서빙한다.
7. 돈 더미가 생긴다.
8. 돈을 수거한다.
9. 첫 건설 존에 돈을 투입한다.

## 19. 기술 설계

### 19.1 Unity 사용 이유

이 게임은 모바일 직접 조작, 캐릭터 이동, 충돌/트리거 존, 가상 조이스틱, 광고/IAP, 2.5D 맵 구성이 중요하다. 따라서 현재 방향에서는 Unity가 잘 맞는다.

### 19.2 런타임 구조

```
PlayerController
→ StackHolder
→ InteractionZone
   → GatherZone
   → CookStation
   → TableZone
   → BuildZone
   → HireZone
CustomerSpawner
Customer
MoneyPile
StaffAgent
EconomyManager
SaveManager
```

### 19.3 데이터 구조

- 재료, 메뉴, 손님, 업그레이드는 ScriptableObject로 관리한다.
- 플레이어 진행도, 골드, 업그레이드 레벨, 해금 시설, 직원 상태는 SaveData에 저장한다.
- M1 단계에서는 코드 생성 그레이박스도 허용하지만, M2부터는 프리팹/데이터 기반으로 전환한다.

### 19.4 씬 구조

| 씬 | 역할 |
|----|------|
| Bootstrap | 매니저 초기화, 세이브 로드, SDK 초기화 |
| MainRestaurant | 실제 플레이 맵 |

초기에는 `Bootstrap.unity` 하나에 자동 생성 월드를 둬도 된다. 단, 출시 구조에서는 플레이 맵과 매니저 초기화를 분리한다.

## 21. 현재 구현과 연결

현재 Unity 프로젝트의 `Assets/_Project/Scripts/Arcade`는 이 GDD의 M1 방향을 검증하기 위한 첫 뼈대다.

현재 목표는 전략형 시스템을 더 키우는 것이 아니라, 다음 순서로 직접 이동형 아케이드 타이쿤을 선명하게 만드는 것이다.

1. 모바일 가상 조이스틱을 실제 플레이 UI로 고정
2. 생선 외 자원 노드 추가
3. 생산 시설 2종 이상 추가
4. 돈 더미와 건설 존을 더 잘 보이게 개선
5. 직원 자동 운반을 맵 위에서 보이게 구현
